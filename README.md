# Kristiyana Marcheva, portfolio site (kmarcheva.com)

Plain HTML, CSS and a little JavaScript. No build step: open `index.html` in a browser to view it locally.

## Files
- `index.html`, `work.html`, `about.html`, `contact.html`, `404.html`
- Project pages: `notiere.html`, `kult-drinks.html`, `the-family-chemist.html`, `hooks-4-change.html`, `experimental-formats.html`
- `assets/css/style.css`: shared styles (colours, type, nav, buttons, footer, loading screen, animations)
- `assets/css/home.css`, `work.css`, `project.css`, `about.css`, `contact.css`: page layouts
- `assets/js/main.js`: loading screen, nav pill, Work filters, design process pop-up
- `assets/img/`: all images (your original files) and the logo
- `favicon.ico`, `favicon.svg`, `apple-touch-icon.png`: browser tab and home-screen icons
- `CNAME`: tells GitHub Pages to use kmarcheva.com (don't delete it)
- `robots.txt`, `sitemap.xml`: help Google find every page

## Small edits on GitHub
- **Text**: open the page's `.html` file on github.com, click the pencil icon, edit, then click "Commit changes". The live site updates in about a minute.
- **Swap an image**: in `assets/img/`, upload a new file with exactly the same name ("Add file" → "Upload files"). It replaces the old one everywhere.
- **Highlighted words**: wrap a word in `<em>…</em>` and it is set in Caslonian bold italic.
- **The Family Chemist logo animation**: when it's ready, send it over and it goes next to the logo.

## Visitor stats (Cloudflare Web Analytics, free, no cookie banner)
Each page has a line near the bottom: `<!-- Visitor stats: paste your Cloudflare Web Analytics snippet on the next line -->`.
Paste the snippet Cloudflare gives you on the line under it, on every page.

## Fonts
Hanken Grotesk loads from Google Fonts. Caslonian Std L loads from your Adobe Fonts kit (`tfs3pzl`):
at fonts.adobe.com → Web Projects, add `kmarcheva.com` and `www.kmarcheva.com` to the project, or the
highlighted words fall back to Libre Caslon.
